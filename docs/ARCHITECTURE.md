# Архитектура

frontend/ — React + TypeScript, адаптер fixture/real, формы и визуализации.
backend/ — Python API, парсер CSV, проверка плана, вычисления, отдельный ИИ-адаптер и экспорт.
contracts/ — JSON fixtures и синтетические CSV. Модели API описаны в docs/API_CONTRACT.md.
Для хранения версии наборов, планов и запусков backend выбирает простой механизм с изоляцией пользовательской сессии.
UI не вычисляет исследовательские показатели, сервер не доверяет выводам модели.
Точный набор и версии зависимостей фиксируют исполнители после проверки. Первая интеграция использует один origin с proxy.
