# Границы доверия

Ключ ИИ только на сервере, секреты вне Git. Файл и его содержимое — недоверенные данные.
Лимиты 10 МБ/50 тысяч строк, ограничение времени и количества запросов. Явный перечень поддерживаемых операций.
CSV и текст не исполняются. Модель получает минимальный контекст, инструкции из данных не исполняются.
Сессионная изоляция всех dataset/plan/run/export. Негативная проверка доступа из другой сессии.
Пользователь явно выбирает передачу данных внешнему сервису. Для демонстрации только открытые и синтетические данные.
Экспорт CSV не должен запускать формулы при открытии в таблицах. Логи исключают содержимое файлов и секреты.
Публичность кода не даёт права раскрывать реальные пользовательские данные.
