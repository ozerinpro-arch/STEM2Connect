# Цель и критерии

ResearchLens помогает проверить, какие аналитические решения меняют исследовательский вывод. Трек Scientific Research.
Основной пользователь — исследователь или аналитик, который умеет читать таблицу.

## Полный сценарий

CSV → схема и вопрос → подтверждение плана → расчёт → сравнение → детали результата → объяснение → экспорт.
Один набор до 10 МБ/50 тысяч строк. Первая версия — бинарный исход, две группы, одно поле стратификации. Поддержка числового исхода и регрессии — следующий приоритет после полного бинарного сценария.

## Приёмка

- Предусмотрены импорт своего поддерживаемого CSV и встроенные синтетические примеры.
- Эталон даёт A=27%, B=73%, по простым A=90%, B=80%, по сложным A=20%, B=10%.
- Равные веса сложности дают A=55%, B=45%. Это другая целевая смесь, она обозначена отдельно.
- Версия плана фиксируется. Перезапуск повторяем, отсутствующие группы и невалидные значения видны.
- Интерфейс раскрывает числитель, знаменатель и формулу.
- ИИ объясняет вычисленные результаты. Приложение проходит ошибки и недоступность модели.
- Экспорт позволяет воспроизвести расчёт из чистой среды.
- Клавиатура, мобильный экран, loading/empty/error состояния проверены.
- Заявка включает публичный код, README, описание, видео до 6 минут и всех участников.
