# Визуальный язык

Английский интерфейс, Contour по умолчанию. Перед реализацией выбрать доступный референс.
Слева данные/план, в центре график, справа раскрытые детали. На телефоне последовательные шаги.
Один акцент, нейтральные поверхности, читаемая типографика. Цвет не является единственным носителем смысла.
Состояния loading, empty, error, unsupported, model unavailable. Клавиатура, контраст, reduced motion.
Саша отвечает за frontend; фактические токены и выбранный референс добавить после согласования.
