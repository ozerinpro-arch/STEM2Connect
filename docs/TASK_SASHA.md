# Саша — frontend и пользовательский сценарий

## Общая цель

Вместе с Владиславом создаём ResearchLens для STEM2Connect. Это сайт для проверки исследовательских выводов. CSV и вопрос превращаются в подтверждённый план, графики и воспроизводимый отчёт.

Владислав делает backend, расчёты, ИИ и ZIP. Ты делаешь frontend, визуализацию, доступность и демонстрационный проход. Доли примерно равные по усилиям, при интеграции помогаете друг другу.

## Твои границы

frontend/**, клиентские проверки, UI-документация и сценарий видеодемо. backend/** ведёт Владислав.
Не меняй API самовольно. Контракт — docs/API_CONTRACT.md, ответы — contracts/fixtures/*.json.
Ветка codex/frontend-sasha, отдельный PR. Для push в общий репозиторий нужен GitHub-доступ. До выдачи доступа можно использовать fork и PR.

## Обязательные экраны

1. Старт с двумя примерами и загрузкой своего CSV.
2. Предпросмотр таблицы, назначение колонок и текст исследовательского вопроса.
3. Подтверждение плана, выбор двух групп и одного фактора стратификации, целевые веса.
4. Рабочая лаборатория — слева план, в центре результаты, справа детали выбранной оценки.
5. Сравнение общего показателя с группами и отдельная панель стандартизированного результата.
6. Объяснение от API с привязкой к оценкам и кнопка экспорта.
7. Состояния пустых/неподдерживаемых данных, timeout, ошибки API/ИИ и повторного запуска.

## Главная демонстрация

Синтетические тесты систем A/B. Общий результат A=27%, B=73%. В простых задачах A=90%, B=80%, в сложных A=20%, B=10%.
Пользователь раскрывает состав выборки. При весах сложности 50/50 итог A=55%, B=45%.
Не представлять стандартизацию как единственную научную истину. На экране должны быть вопрос, целевая смесь, единицы и количество наблюдений.
Открой каждое число — покажи числитель, знаменатель и формулу из backend.

## Дизайн

Интерфейс на английском. Визуальный язык Contour по доступным в вашей сессии инструкциям. Перед реализацией выбери конкретный референс и покажи рабочий экран.
Графики и действия занимают основной экран. Сохраняй плотность лаборатории, понятную иерархию, спокойную поверхность и один акцент.
Цвет дополняется текстом и формой. Для графиков доступна таблица. Мобильный вид последовательный. Анимация объясняет переход и учитывает reduced motion.
Проверить клавиатуру, фокус, подписи и контраст.

## Как начать независимо

В адаптере API переключай fixture и real режим через настройку окружения. На экране fixture-режима явно покажи Demo data. Сначала полностью пройди пример на contracts/fixtures.
Источник чисел — fixtures/API, вычисления в компонентах не дублировать. Когда Владислав даст base URL, переключи адаптер и проведи тот же сценарий.

## Приёмка

Свои CSV доходят до API. Перезагрузка восстанавливает run по id при действующей сессии. Все значения соответствуют API. Ошибка модели не скрывает готовый расчёт.
Полный проход с клавиатуры и на телефоне, пустые и ошибочные состояния. API ключи отсутствуют в браузере.
Подготовь 4–5-минутный сценарий демо и проведи короткие пробы с 3–5 людьми. Пиши только фактические результаты и согласованные сведения.
