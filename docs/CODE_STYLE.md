# Соглашения

Читаемые имена, простые функции и отдельная логика расчётов. Избегать дублирования серверных расчётов в UI.
API-адаптер frontend изолирует работу с сервером и fixtures.
У каждого обязательного числового результата есть проверка эталона.
Не писать фиктивные команды или успешные результаты проверок. Добавлять фактические команды в README по мере реализации.
