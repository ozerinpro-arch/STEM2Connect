# Владислав — backend и научная корректность

## Общая цель

С Сашей создаём ResearchLens для STEM2Connect. Пользователь проверяет утверждение на CSV, видит изменение результата при понятном выборе групп и весов и скачивает воспроизводимый эксперимент.

## Твои границы

backend/**, расчёты, API, серверный ИИ, экспорт, зависимости backend и документация запуска. frontend/** ведёт Саша.
Общий контракт — docs/API_CONTRACT.md. Изменения contracts/** согласовывайте.

## Обязательные результаты

1. Python API с импортом и проверкой CSV. Поля, типы, пропуски, лимиты и понятные ошибки.
2. Реализация синтетических примеров и пользовательского файла по тому же пути расчёта.
3. Сохранение подтверждённого плана и запуск расчёта. Размеры групп, сырые доли, стандартизация по явно заданным весам.
4. Открываемые данные каждой оценки и сопоставление только одинаково определённых величин.
5. Интеграция ИИ через доступный пользователю сервис. Структурированный ответ, привязка объяснения к результатам. Ключ на сервере. Ошибка модели возвращается отдельно.
6. ZIP с CSV по запросу пользователя, планом, версиями, результатами и скриптом повторного расчёта.
7. Проверки эталона, неверного CSV, отсутствующей категории, повторного запуска и доступа к чужим данным.
8. Проверить чистый запуск и воспроизведение экспорта, описать реальные команды в README.

## Порядок

Первый результат — GET health, fixture endpoint и полный расчёт без ИИ. Затем импорт CSV, планы и история runs, экспорт. После этого ИИ и самостоятельная проверка backend.

## Приёмка

Все обязательные пункты PRD проходят через API. Перестановка строк не меняет чисел. API соответствует JSON fixtures. Ошибки имеют код и понятный текст. Неизвестные значения не превращаются в нули. Экспорт воспроизводится независимо от frontend.
Предложенные технологии — Python, FastAPI, pandas; подключать готовые библиотеки после проверки совместимости. Конкретная модель и хостинг ещё не выбраны.

## Совместная интеграция

Передать Саше base URL и команды запуска. Вместе проверить один встроенный и один пользовательский CSV, ошибки ИИ, скачивание ZIP и перезагрузку страницы. До слияния PR сверить контракт.
