# Проверки

Владислав проверяет расчёт через API, CSV, лимиты, ошибки, повторный запуск, изоляцию ресурсов и чистое воспроизведение экспорта.
Саша проверяет сценарий через браузер с fixtures и реальным API, клавиатуру, маленький экран, сбои загрузки и модели.
Совместно выполняют встроенный пример, независимый CSV и повторное открытие run.
Эталон A27/B73, easy90/80, hard20/10, standardized55/45. Числа в JSON — доли.
Для второго набора результат должен сохраняться по группам. Оба примера синтетические.
Тестовые команды ещё не определены, код отсутствует. Исполнители добавляют команды и результаты после реализации.
